What the desktop app records — violation_dict schema

Extracted from HelmetViolation.to_dict() / violations_to_dict() in helmet_detection_yolo8_max_accuracy.py. The desktop app also saves evidence images via the violation_images table (image_path).

{
  "violation_id": "CAM0_HELMET_000123",
  "timestamp":   "2026-10-20T14:03:11.123456",
  "camera_id":   1,
  "rider_bbox":  [x, y, width, height],
  "helmet_bbox": null,
  "confidence":  0.87,
  "detection_type": "no_helmet_detected"
}

Saved to SQLite violations with columns violation_id, type, camera_id, timestamp, confidence, officer, details, image_path, processed.

Companion UI only — no model runs in the browser. Detection confidence threshold in repo: 0.60 (IoU 0.45) · seatbelt & roundabout detectors are commented stubs in source/main_app.py.
