Quick start

Requirements · quoted from README

  1. 1

    Install Python dependencies

    pip install -r requirements.txt

    Python 3.8+ required. Use the provided requirements.txt.

  2. 2

    Install Ollama, then run the model

    ollama run llama3

    Ensure ollama is working from your terminal. The app uses it to generate prerequisites and questions.

  3. 3

    Run the application

    python app.py

    Visit the web app at http://127.0.0.1:5000.

How the flow works

Syllabus in · PDF out

  1. 1 Select syllabus board / class / subjects / chapters
  2. 2 Prerequisites LLM-detected prior knowledge
  3. 3 Generate MCQs drafted by llama3
  4. 4 Review verify and pick questions
  5. 5 Export PDF download paper or CSV

From requirements.txt

Requirements

  • flask
  • fpdf
  • requests
  • python-dotenv
  • Pillow
  • reportlab

Honest note: generation needs the local LLM (Ollama running with llama3); the UI is served by Flask. Pages open without Ollama, but prerequisite and question generation will fail until it is running.
