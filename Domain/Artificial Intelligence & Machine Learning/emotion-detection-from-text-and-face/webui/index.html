Backend offline — start the FastAPI server

This page shows only what the real API returns, so nothing renders until it answers. From the project's backend/ directory (per HOW_TO_RUN.md):

cd backend
python -m venv venv
# Windows: venv\Scripts\activate   ·   macOS/Linux: source venv/bin/activate
pip install -r ../requirements.txt
uvicorn app:app --reload

Notes quoted from the project docs:

  • On the first run the system automatically downloads the ~200MB emotion model from HuggingFace — give it time and keep the connection stable.
  • Redis on port 6379 is optional; without it the API degrades gracefully and skips caching.
  • Equivalent start command from the README: python -m uvicorn app:app --reload --host 0.0.0.0 --port 8000.
  • Verify with GET http://127.0.0.1:8000/health → {"status": "ok"}, then press Recheck.
