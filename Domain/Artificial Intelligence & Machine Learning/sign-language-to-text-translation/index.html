    CLI quickstart

    Real commands from cli.py and the README. slt is the console script defined in pyproject.toml.

    • List commands — cli.py

      slt

    • Inspect downloaded assets — cli.py help for slt assets tree

      slt assets tree

    • Translate a sentence — README example (Urdu)

      slt translate --model-code rule-based --text-lang urdu --sign-lang pk-sl --sign-format video "ایک سیب اچھا ہے۔"

    • Complete a sequence with language models — README example

      slt complete '<' --model-code urdu-mixed-ngram --join ''

    • Embed videos — cli.py help for slt embed

      slt embed dataset/*.mp4 --model-code mediapipe-pose-2-hand-1 --embedding-type all --processes 4 --save-format csv

    Install first: pip install sign-language-translator (or pip install -e ".[all]" in a clone). Heavy extras — torch, mediapipe — are optional and only needed for embeddings.

    Build your own translator

    The framework is designed for extension — the README’s recipe, in order:

    1. Collect a word-level dictionary of sign videos plus a JSON mapping from text tokens to those video filenames.
    2. Subclass slt.languages.TextLanguage — implement preprocess, tokenize, sentence_tokenize and token classification.
    3. Subclass slt.languages.SignLanguage — implement tokens_to_sign_dicts (token → clip labels) and restructure_sentence (your sign language’s grammar).
    4. Pass both objects to slt.models.ConcatenativeSynthesis(text_language=..., sign_language=..., sign_format=...) and call .translate(text).
    5. Register short codes in config/enums.py and the factory functions (get_model(), get_text_language()), then generate synthetic training data for deep models.

    README, verbatim: “To create a rule-based translation system for your regional language, you can inherit the TextLanguage and SignLanguage classes and pass them as arguments to the ConcatenativeSynthesis class.”
