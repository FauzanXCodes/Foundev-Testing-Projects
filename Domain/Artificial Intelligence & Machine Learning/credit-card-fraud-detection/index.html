SETUP REQUIRED — API NOT REACHABLE

The scoring API at http://127.0.0.1:5000 did not respond. models/model.pickle and data/creditcard.csv are not shipped in this repo, so train the model first, exactly as described in the project README:

  1. Download the dataset and put creditcard.csv under data/ — creditcard.csv.zip (README step 2).
  2. pip install -r requirements.txt
  3. python src/train.py — from the repo root; ends with a model.pickle file under models/.
  4. Launch the Flask app from the repo root: 
    export FLASK_APP=src/flask_app.py
flask run
    or equivalently: python -m flask --app src/flask_app.py run
  5. Verify: POST http://127.0.0.1:5000/predict with an application/json body of the form {"features": [30 floats]}.

NOTE: src/flask_app.py sends no CORS headers. If Flask answers (e.g. via curl) but this page still reports a network error, the browser is blocking the response across origins — serve this page and the API from the same origin, or add flask-cors in your own local environment.
