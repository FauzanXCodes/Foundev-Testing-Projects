LeafLens

A CNN image classifier for plant leaf disease — fifteen categories, built for agricultural monitoring. Photograph a leaf from the field, and the network reports whether it reads as healthy or diseased and which category its symptoms belong to.

Method

How it works

Three stages, as described by the project README and its training notebook.

  1. 01

    Image in

    A photograph of a single leaf — symptoms or healthy tissue — is taken in the field and loaded on the bench above. The input is always an image.

  2. 02

    Preparation

    The photo is decoded and shaped into the input the network expects before it is classified. The exact pipeline lives in Code.ipynb alongside the training code.

  3. 03

    CNN, 15 classes

    A convolutional network scores all fifteen categories. Per the README, the output says whether the leaf is healthy or diseased and which category it belongs to.

Field notes

For researchers

The README presents this as a simulation study: a CNN trained on samples from fifteen categories, reporting minimum error during training and better accuracy in classification, with output that reveals healthy-or-diseased status and the category it belongs to.

What is present in this repository: the Django page project, the training notebook Code.ipynb, and this interface. What is absent: trained weights, the list of the fifteen label names, and any prediction endpoint — so this notebook shows structure and honesty rather than invented diagnoses.

To make the bench live, add a prediction view and point the form at it: POST /predict → { "disease": "…", "confidence": 0.0 } (proposed, not implemented).
