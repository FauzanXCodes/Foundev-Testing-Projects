Engine

Eye Aspect Ratio

EAR = A + B 2 · C

A and B are the vertical landmark pairs, C the horizontal width — the exact distances used by eye_aspect_ratio() in blinkDetect.py.

Thresholds in the backend

EAR < 0.27
Eye counted as closed — thresh = 0.27 in blinkDetect.py.
0.15 s / 1.5 s
blinkTime ignores short closures as false blinks; drowsyTime fires the alarm after a sustained closure.
0.25 · 20 frames
EAR_THRESHOLD + CONSEC_FRAMES in streamlit_app/streamlit_app.py → DROWSY in the web app.

Run the real backend

streamlit run streamlit_app/streamlit_app.py
python blinkDetect.py
python main.py
  • The dlib 68-landmark model shape_predictor_68_face_landmarks.dat is not shipped — download it from dlib.net and place it in models/ (see README).
  • models/haarcascade_frontalface_default.xml is present in this repository.
  • Webcam frames are processed locally by OpenCV/dlib or MediaPipe via streamlit-webrtc — no video leaves the machine, and neither backend exposes a JSON API.
  • This page therefore simulates the EAR signal in the browser; it does not read your camera.
