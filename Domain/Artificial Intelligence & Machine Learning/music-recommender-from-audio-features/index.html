Method (from repo)

This UI replicates the exact algorithm from src/main_cosine_similarity.py:

  1. Load CSV — semicolon-separated with quoted-field handling; columns include danceability and speechiness (trailing spaces).
  2. Features — exactly ['bpm','energy','danceability ','dB','liveness','valence','duration','acousticness','speechiness ','popularity'].
  3. Min-max normalization — for each feature, scale to [0,1] over the full dataset: (x - min)/(max - min).
  4. Cosine similarity — between selected song vector and every row; sort desc; top N.

All computations run client-side in vanilla JS over the repo's dataset — real functionality, deterministic.
