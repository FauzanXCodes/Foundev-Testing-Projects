NO REST API IN THIS REPO

This repository ships a Streamlit backend only. To run real plate detection with the included weights:

pip install -r requirements.txt
streamlit run app.py
  1. Open http://localhost:8501.
  2. Sidebar → activity type Upload Image, upload the file you staged here (PNG/JPG/BMP/JPEG).
  3. The app loads model/last.pt via torch.hub.load("ultralytics/yolov5", "custom", path="model/last.pt") with conf 0.5 / IoU 0.45 and runs model(img, size=640).
  4. Rendered detections are saved as downloads/output_<filename> and offered back for download.
  5. Alternatively pick Live Video Feed in the sidebar to run webcam detection (cv2.VideoCapture(0)).

Your staged file stays in this browser — nothing is uploaded anywhere from this page.

About the model

Factual inventory of what this repository actually contains and runs.

Detector

Custom-trained YOLOv5 number-plate detector. Weights ship in the repo at model/last.pt (14,378,245 bytes). Loaded in app.py with:

torch.hub.load("ultralytics/yolov5", "custom", path="model/last.pt")

Runtime settings from app.py: conf = 0.5, iou = 0.45, inference size = 640.

Inference pipeline

  1. Upload image (PNG/JPG/BMP/JPEG) or enable webcam.
  2. File saved to uploads/.
  3. results = model(img, size=640) → results.render().
  4. Annotated frame saved to downloads/output_<name> (JPEG).
  5. Streamlit renders the image and offers a download button.

OCR is not implemented

Project metadata lists a stack of “Python; OpenCV; Tesseract” and a goal mentioning OCR cleanup — but app.py never calls Tesseract or any OCR library. The app detects plate regions with YOLOv5 and renders annotated images; it does not read/extract plate text. Treat any “recognition” claim as localisation only.

Deployment options (real files)

  • Local: streamlit run app.py (from README)
  • Docker: Dockerfile — python:3.7 base, docker build -f Dockerfile -t app:latest . then docker run -p 8501:8501 app:latest
  • Heroku-style: Procfile → web: sh setup.sh && streamlit run app.py; runtime.txt pins python-3.7.13

Dependency pins (age warning)

requirements.txt pins an older stack: torch==1.8.1, torchvision==0.9.1, streamlit==1.9.0, opencv-python==4.5.5.64, Pillow==9.1.0, Flask==2.1.2. The @st.cache decorator used in app.py predates @st.cache_data/@st.cache_resource in modern Streamlit — install the pinned versions for a faithful run.

Provenance
