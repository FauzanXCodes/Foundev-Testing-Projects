How recognition works

01

Haar detect

haarcascade_frontalface_default.xml locates faces — detectMultiScale(gray, 1.2–1.3, 5) in both take_img() and the attendance loop. The _alt cascade is also shipped in the repo.

02

LBPH predict

cv2.face.LBPHFaceRecognizer compares the face crop against Trainner.yml. A match is accepted when conf < 70 (lower distance = closer match); otherwise the face is drawn as Unknown.

03

Write CSV

Accepted faces land in Attendance/Subject_YYYY-MM-DD_HH-MM-SS.csv with columns Enrollment,Name,Date,Time. If MySQL is up, a mirrored table is created in the Face_reco_fill schema.

Dependencies & honest notes

  • opencv-contrib-python is required — cv2.face (LBPH) is not in the base opencv-python wheel.
  • pymysql is optional; without MySQL the app still writes CSVs. Schemas used: Face_reco_fill (auto) and manually_fill_attendance (manual), user root on localhost.
  • AMS_Run.py contains hardcoded absolute paths (attendance CSV targets point at the original author’s machine) — edit them before relying on file outputs.
  • The “Check Register students” panel uses a hardcoded demo admin login in AMS_Run.py (credentials live in that file — not repeated here).
