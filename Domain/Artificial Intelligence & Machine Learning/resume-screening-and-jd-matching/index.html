    About the real engine

    What actually runs in Streamlit

    • 384-dim Sentence embeddings from all-MiniLM-L6-v2 (SentenceTransformers).
    • cosine_similarity ranks every resume against the job description (src/matcher.py).
    • spaCy en_core_web_sm + PhraseMatcher extracts matched / missing / extra skills (src/preprocessor.py).
    • PDF DOCX TXT parsing with pdfplumber and python-docx (src/extractor.py).
    • cached load models load once per session through @st.cache_resource (app.py).
    • explainable output fields: matched_skills, missing_skills, extra_skills, skill_match_percentage, summary.

    Run the real app

    1. venv\Scripts\activate
    2. pip install -r requirements.txt
    3. python -m spacy download en_core_web_sm
    4. streamlit run app.py → opens at http://localhost:8501

    On first run the model weights (~90MB) download from Hugging Face and are cached locally — later runs work offline.
