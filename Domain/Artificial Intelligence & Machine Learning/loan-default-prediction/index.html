    About the pipeline

    A Kaggle prize solution for the Loan Default Prediction competition: a two-stage scikit-learn GradientBoosting pipeline over anonymized features f1..f777.

    Stage 1 — Default classifier

    models.DefaultClassifier wraps GradientBoostingClassifier and binarizes the target (y > 0 → 1) to estimate P(default). Hyper-parameters from train_predict.py:

    GradientBoostingClassifier(
    loss='deviance', learning_rate=0.01, n_estimators=3000,
    subsample=0.6, min_samples_split=12, min_samples_leaf=12,
    max_depth=6, random_state=1357)
# steps: FeatureSelector -> Imputer(median) -> StandardScaler -> clf

    Stage 2 — Loss regressor

    models.PartialRegressor fits GradientBoostingRegressor on log(loss) for defaulters only, exponentiates, and clips predictions to [1, 100] severity units.

    GradientBoostingRegressor(
    loss='ls', learning_rate=0.0075, n_estimators=5000,
    subsample=0.5, min_samples_split=20, min_samples_leaf=20,
    max_leaf_nodes=30, random_state=9753)
# y = log(y[y > 0]); pred = clip(exp(pred), 1, 100)

    Submission rule — the 0.60 cut

    submission['loss'] = pred_loss * (prob_default_test.values > 0.6)

    Loss is applied only when P(default) > 0.6. The verdict bands on this desk are informed by that cut, but the numbers themselves are the page’s demo heuristic.

    Legacy Python 2 pipeline — not runnable as-is on modern Python

    • Python 2 syntax: print statements in train_predict.py fail on Python 3.
    • Removed API: sklearn.preprocessing.Imputer was deprecated and removed (use SimpleImputer).
    • Renamed losses: loss='deviance' / 'ls' are now 'log_loss' / 'squared_error'.
    • Old pandas: dtype.iteritems() and np.float are gone in current versions.
    • No data: train_v2.csv / test_v2.csv come from Kaggle and are not in the repo.

    How to run (real command)

    python train_predict.py path/to/data/folder
# expects train_v2.csv and test_v2.csv in that folder
# writes test_proba.csv and submission.csv

    Requires an old pandas + a scikit-learn build from 2015 (README pins dev commit 884889a4). Expect to port the code before it runs today.
